# Backlog

`issues.csv` contains 20 prioritized GitHub issues with acceptance criteria and rough estimates. The first 12 P0 issues form the critical path; P1 contains SAM and the scientific ablation. Use `scripts/create-issues.sh` only after creating the remote and confirming the repository target. The script creates issues but **does not** create project fields, milestones, labels, or a GitHub Project; those are manual setup steps.

Priority: P0 essential, P1 important, P2 post-hackathon. Milestones M0 foundation, M1 perception, M2 evidence, M3 3D, M4 research, M5 release.
