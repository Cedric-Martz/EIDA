# ADR-011: Adopt EIDA as the project name

Status: Accepted

## Decision

Use **EIDA**, expanded as **Evidence-based Intelligence for Disassembly & Analysis**, for the repository, package and product interface. The user explicitly selected this name on 2026-10-27.

## Consequences

The name communicates the evidence-first method and replaces the temporary “Physical Reconstruction Lab” title. This engineering decision is not legal clearance for a trademark or domain; that review remains separate.
